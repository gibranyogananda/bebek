# Bebek Gongso Kinanthi - Web Bootstrap

Website one-page untuk tugas Latihan Web 03 menggunakan Bootstrap 5.

## Struktur
- index.html
- style.css
- script.js
- assets/
- repo.txt

## Section
1. Home / Hero
2. Layanan
3. Menu
4. Tentang
5. Paket Nasi Box & Prasmanan
6. Review
7. Kontak

## Database
Dua section disiapkan untuk Firestore:
- Menu -> collection `menus`
- Review -> collection `reviews`

Isi konfigurasi Firebase pada `script.js` agar database aktif.

## GitHub
Gunakan branch `Web-Bootstrap` untuk pengembangan.
Setelah final, branch tersebut dapat digabungkan ke `main`.

## Catatan
Bootstrap 5 digunakan untuk grid, navbar, card, button, form, responsive layout, dan komponen lainnya.
